# Dashboard Patterns

## Shared Shell

- Use one responsive content width and one spacing rhythm across all routed pages.
- Keep sidebar, topbar, and overlay behavior predictable on mobile.
- Prevent long user names or action groups from colliding inside the header.

## Auth Screens

- Pair strong copy with one clear form panel.
- Keep the background visible, but soften overlays only as far as readability allows.
- Keep form actions stacked or full-width on narrow screens.

## Data Views

- Use filter bars that stack naturally on small screens.
- Prefer card fallbacks for application/job rows on phones.
- Keep destructive and edit actions reachable without tiny icon targets.

## Dashboard Views

- Let summary cards wrap in a predictable grid.
- Give charts explicit height and enough spacing from surrounding controls.
- Use a mobile-friendly fallback for recent activity when full tables become cramped.

## Forms and Modals

- Group related fields in one column first, then split into two columns on wider screens.
- Keep save and cancel actions near the bottom edge of the form and easy to reach.
- Let modals become full-height on phones when needed instead of clipping content.
